Enterprise-Grade Architecture

Designed according to rigorous academic software engineering standards for security, performance, and maintainability.

🔒

Server-Side Answer Security

Correct answer keys are strictly retained on the Java backend. The browser receives sanitized questions, preventing client-side inspection or tampering.

⚡

Automatic Evaluation Engine

Evaluates candidate submissions instantly against database answer keys, calculates percentages, and assigns PASS or FAIL status based on configurable criteria.

⏱️

Intelligent Examination Engine

Features a live countdown timer, automatic submission upon expiration, question palette tracking, and double-submission prevention.

💾

SQLite Relational Persistence

Full ACID compliant relational storage using Spring JDBC and SQLite JDBC with enforced foreign keys, indexes, and parameterized queries.

📊

Admin Results Dashboard

Real-time performance analytics, search by student name/ID, filtering by subject and pass/fail status, and one-click CSV export.

🖨️

Print-Ready Scorecards

Polished result verification certificate with dedicated print stylesheet allowing instant PDF or paper transcript generation.
