System Layered Architecture

ExamFlow enforces strict separation of concerns across multiple application tiers:

  • Presentation Layer: Thymeleaf templates, custom vanilla CSS design tokens, and modular JavaScript controllers.
  • Controller Layer: Handles HTTP endpoints, form data binding, and input validation (StudentExamController, AdminDashboardController).
  • Business Logic & Evaluation Layer: Enforces question sanitization, transactional grading, percentage computation, and pass/fail classification.
  • Data Access Layer: Spring JdbcTemplate with parameterized SQL queries preventing SQL injection vulnerabilities.
  • Database Layer: SQLite file-based relational store enforcing foreign key integrity across students, exams, questions, attempts, answers, and results.

Automatic Evaluation Engine Specifications

Grading Formula:

Percentage = (Marks Obtained / Maximum Marks) × 100

Status = (Percentage ≥ Exam Passing Percentage [Default 40.0%]) ? "PASS" : "FAIL"

Answer keys are never transmitted to the browser before or during test execution. Even if an exam session is submitted via timeout, the server autonomously pulls the registered answers, computes scores, records individual question outcomes, and archives the attempt with an immutable UUID.
